## Technical repairs

- Complete Open Graph and Twitter metadata on all public pages, preserving exact existing page titles and descriptions.
- Remove build-time fabricated `lastModified` dates from the sitemap.
- Link legal documents directly to their canonical root routes instead of the intermediate `/legal/` redirects.
- Redirect the duplicate `www` hostname to the existing apex canonical origin, preserving paths and query strings.
- Inline the existing CSS through Next's supported build option to remove blocking stylesheet round trips.
- Deliver the existing client artwork as lossless WebP with intrinsic dimensions.
- Remove the inert homepage hero/scroll coordinator dependency. The approved hero is already static.
- Preserve tactile button feedback through native Web Animations without loading unrelated ScrollTrigger code.
- Cache successful normalized public jobs responses for five minutes through the existing Cloudflare Cache API. The OpenNext static-assets cache cannot perform runtime revalidation. Errors and form submissions are not cached. Upstream job requests are bounded to 15 seconds.
- Route job Apply links to the career form, retaining the selected role in the submission.
- Require explicit upstream `ok:true`. Missing CV/email flags remain unknown instead of being reported as successful. Reject oversized message payloads before normalization can truncate them into validity.
- Follow Google ContentService response redirects explicitly as credential-free GET requests. Send the original POST once, reject unrelated destinations and POST-preserving redirects, and bound the exchange. Reject non-object JSON and retain only sanitized transport diagnostics for malformed responses.
- Expose the existing script's audit outcome separately from business persistence. A failed audit does not prompt duplicate submission. Server error logs avoid upstream URLs and response payloads.
- Retain every standard Lighthouse JSON and HTML run, including failed/baseline phases, without changing scoring or throttling.

## Evidence rules

A website receipt proves API completion. Sheet readback proves storage. Drive permission metadata proves that a test file was not publicly shared. A mail-send flag proves accepted sending, while inbox readback proves receipt for that mailbox. These are separate claims.

Lighthouse 100 does not establish search ranking or Google indexing. It is a lab score under the recorded standard profile. Retain repeated runs and report variation honestly.
